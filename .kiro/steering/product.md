# Poltergeist Commits

- Keep runtime browser-only and free of paid APIs, assets, or services.
- Never execute repository code, request tokens, or modify remote repositories.
- Every visual finding must retain its source, observation date, confidence, and next step.
- Preserve bounded sampling and disclose partial coverage. Never imply a complete health or security assessment.
- Preserve keyboard access, text/table alternatives, reduced motion, safe React text rendering, and validated evidence URLs.
- Start audio only after explicit user interaction; preserve mute, volume, background suspension, and disposal. Avoid flashing effects and respect both system and manual motion reduction.
- After changes to analysis or evidence mapping, run `npm test` and `npm run build`.
- Do not commit, push, publish, or add paid dependencies without explicit user authorization.
